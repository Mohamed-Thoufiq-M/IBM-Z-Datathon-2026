## Project Overview
Our project, 'Smart Real-Time Fraud Detection Dashboard,' is an enterprise-grade AI solution designed to monitor, analyze, and flag high-risk credit card transactions instantly.

* **Cloud Platform:** IBM Z / LinuxONE Community Cloud
* **Instance Name:** SoloCoderVM

* **OS Image:** Ubuntu24.04-Datathon
* **Core Stack:** Python, Streamlit, Jupyter Lab

## Key Features
1. Live Transaction Monitor with real-time risk scoring.
2. Dynamic risk threshold control panel for security analysts.
3. Instant visual indicators for safe vs. critical fraudulent transactions.
